# Контрольная точка

**Дата:** 10 февраля 2026  
**Тег в Git:** `kontrolnaya-tochka`

Текущее состояние сайта зафиксировано. Когда вы напишете **«Контрольная точка»** или **«откати к контрольной точке»**, откат будет выполнен по этой инструкции.

---

## Один раз: создать тег (если ещё не создан)

Выполните в папке проекта:

```bash
cd c:\r\dnd-site
git tag -a kontrolnaya-tochka -m "Контрольная точка"
git push origin kontrolnaya-tochka
```

После этого тег «Контрольная точка» будет сохранён на GitHub.

---

## Как откатить к этой версии

Когда понадобится вернуть сайт к состоянию на 10.02.2026:

```bash
cd c:\r\dnd-site
git fetch origin
git reset --hard kontrolnaya-tochka
git push origin main --force
```

**Внимание:** `--force` перезапишет ветку `main` на GitHub. Все коммиты после контрольной точки будут отменены в удалённом репозитории. Делайте откат только когда уверены.
